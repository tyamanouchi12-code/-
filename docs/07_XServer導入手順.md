# XServer 導入手順

対象: XServer(スタンダード等)、PHP 8.1 以上、MySQL(MariaDB 10.5 以上)。ファイル転送は FFFTP。
所要時間の目安: 30分。

## 1. データベースを作る(サーバーパネル)

1. XServer サーバーパネル → **MySQL設定** → 「MySQL追加」でデータベースを作成(例: `xxxxx_nkc`)。文字コードは **UTF-8** を選ぶ。
2. 「MySQLユーザ追加」でユーザーを作成し、作成したデータベースに **アクセス権を付与**。
3. 「MySQL一覧」で **MySQLホスト名**(例 `mysql1234.xserver.jp`)を控える。

## 2. テーブルと初期データを入れる(phpMyAdmin)

1. サーバーパネル → **phpmyadmin** → 手順1のユーザーでログイン。
2. 左の一覧で作成したデータベースを選ぶ。
3. 上部の **SQL** タブを開き、次のファイルの内容を順番に貼り付けて「実行」。
   1. `sql/001_schema.sql`(テーブル作成)
   2. `sql/002_seed_master.sql`(状態・保管場所・カテゴリの初期データ)
   3. `sql/003_migrate_excel.sql`(Excel からの移行データ)
   4. `sql/004_add_checkouts.sql`(持ち出し機能)
   5. `sql/005_optional_apply_categories.sql`(カテゴリの初期案。任意ですが、次の 006 の前に実行すると Excel の各行が適切なカテゴリに入ります)
   6. `sql/006_restructure_items_by_category.sql`(品目=カテゴリ、内訳=実物の種類・個体 に変換)
   7. `sql/007_add_check_column.sql`(棚卸の確認チェック欄)
4. 実行後、左の一覧に 12 個のテーブルが表示されれば完了。「インポート」タブでファイルを選んで実行しても同じです。

## 3. サーバー専用の設定ファイルを作る

`webapp/app/config.local.php.example` をコピーして `config.local.php` という名前にし、テキストエディタ(UTF-8 で保存できるもの)で開いて手順1の値に書き換えます。

```php
return [
    'db' => [
        'host' => 'mysql1234.xserver.jp',   // MySQL情報タブの「MySQLホスト名」
        'name' => 'xxxxx_tanaoroshi',       // データベース名
        'user' => 'xxxxx_tanaoro',          // MySQLユーザー名
        'pass' => '********',               // パスワード
    ],
    'app' => [
        'name' => 'NKC 在庫管理システム',   // 画面のタイトル
    ],
];
```

`config.local.php` に書いた値は `config.php` の初期値より優先され、**プログラムを上書きアップロードしても消えません**。`config.php` 自体は書き換えないでください(更新のたびに初期値で上書きされます)。

## 4. ファイルをアップロードする(FFFTP)

1. FFFTP でサーバーに接続し、公開ディレクトリ `/(ドメイン)/public_html/` を開く。
2. その中に設置用フォルダ(例 `tanaoroshi`)を作り、`webapp` フォルダの**中身をすべて**アップロードする。
   - 転送モードは「自動」または「バイナリ」。`.htaccess` のような先頭がドットのファイルも必ず転送してください(FFFTP の「フィルタ」設定で隠しファイルが除外されていないか確認)。
   - アップロード後の構成:
     ```
     public_html/tanaoroshi/
       index.php
       setup.php          ← 初期設定後に削除
       assets/style.css, app.js
       app/.htaccess      ← app/ への直接アクセスを禁止
       app/config.php           ← 初期値(触らない)
       app/config.local.php     ← 手順3で作ったサーバー専用の設定
       app/... (bootstrap.php, lib, controllers, views)
     ```
3. サーバーパネル → **PHP Ver.切替** で、対象ドメインの PHP が **8.1 以上**になっているか確認する。

## 5. 最初の管理者を作る

1. ブラウザで `https://(ドメイン)/tanaoroshi/setup.php` を開く。
2. ログインID・表示名・パスワード(8文字以上)を入力して「管理者を作成」。この利用者には全権限が付きます。
3. **`setup.php` を FFFTP で削除**する(利用者が1人でも登録されると動作しませんが、念のため削除してください)。
4. `https://(ドメイン)/tanaoroshi/` を開き、作成した管理者でログイン。

## 6. 動作確認

- 「品目」メニューで 12 件の品目(カテゴリ)の見出しと、その下に内訳(Excel の各行の品名)が表示される。内訳名が空欄の1件は「(内訳名なし)」と表示(Excel 73 行目)。
- 「棚卸」メニューで「2025/12/26 棚卸」「2026/1/6 棚卸」が確定済で表示される。
- 「利用者」メニューから他の利用者を追加し、必要な権限にチェックを入れる。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 「データベースに接続できません」/ Access denied for user 'root'@'localhost' | `app/config.local.php` が無い、または値が違う。上書きアップロードで `config.php` が初期値に戻っても、`config.local.php` があれば影響しない |
| 「ページが見つかりません」(メニューは新しいのに) | 設置フォルダ直下の `index.php` が古い。`webapp/index.php` と `assets/` を再アップロード。画面下部の「版」が最新か確認 |
| 画面が真っ白 / 500 エラー | PHP のバージョンが 8.1 以上か。`app/` フォルダごとアップロードされているか |
| `app/config.php` がブラウザで表示されてしまう | `app/.htaccess` がアップロードされているか(隠しファイル) |
| 文字化け | データベースの文字コードが UTF-8(utf8mb4)か。SQL を貼り付けた phpMyAdmin の文字コードが UTF-8 か |
| ログインできない | setup.php で作成した ID とパスワード。利用者管理で「無効」になっていないか |
