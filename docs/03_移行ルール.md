## 確定した移行ルール

| ID | ルール | 具体的な扱い |
|---|---|---|
| R-01 | 移行対象は B〜H 列(4〜114行目)。I列は備考に含める。A列は移行対象外 | A1「5031879403」は移行しない。I99〜I101 の文字列は該当行の備考(inventory_items.notes)に**追記**する(H列の備考がある99行目は「H列原文」+改行+「I列原文」) |
| R-02 | 原文保持 | 品名・状態・管理No・保管場所・備考は文字列を一切変更しない(全角/半角、スペース、誤字、括弧の未閉じ、「DEL」等すべてそのまま)。管理No 238/239 は文字列 "238" "239" |
| R-03 | 空欄は空欄のまま | 品名(73行目)・状態(26行)・保管場所(39行)が空欄の行は NULL で移行し、推測して埋めない。品名NULLを許すため、移行データについては item_name の必須チェックを適用しない(新規登録画面では必須) |
| R-04 | 結合セルは結合を解いてレコードを分ける | 保管場所の縦結合(E7:E25 等)は、結合範囲内の各行を**別レコード**にし、保管場所の値は各行に持たせる(`02_全行一覧.md` の「保管場所(補完)」列のとおり)。73行目は72行目に統合せず、品名空欄・棚卸数(12/26)=2 の独立したレコードにする |
| R-05 | 棚卸数の空欄は空欄のまま(0にしない) | F列/G列が空欄の行は、その棚卸日の数量を NULL とする。**明細レコード自体を作らない**(画面では空欄表示)。F=0 の 78・90行目は 0 として明細を作る |
| R-06 | 派生項目は移行時に設定しない | メーカー・型番・客先・シリアル・ネットワーク情報は空のまま(品名・備考の中の文字はそのまま残す)。運用開始後に画面から設定する |
| R-07 | 重複候補は統合しない | 5-1〜5-8 はすべて別品目として移行する |
| R-08 | 備考は品目備考のみ | H列(+I列)の原文を inventory_items.notes に保存する。棚卸明細の備考への複製は行わない |
| R-09 | 表示順 | Excelの行順(4→114)をそのまま sort_order にする |
| R-10 | 監査項目 | created_by / updated_by = "excel_import"、created_at / updated_at = 移行実行日時 |
