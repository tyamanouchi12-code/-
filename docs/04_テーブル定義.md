# テーブル定義(DDL案) — B案(品目マスタ + 個体テーブル)

確定日: 2026-09-17。`03_移行ルール.md` の未確定-1〜6 の回答(1:(a) / 2:H1→棚卸期間, H2→入力日付 / 3:B案 / 4:管理Noのある6行のみ個体 / 5:カテゴリは移行時に設定しない / 6:推奨案)を反映しています。

**前提(未確認)**: DBエンジンは **MySQL 8.0** を仮定して書いています。PostgreSQL / SQLite 等に変更する場合は型と AUTO_INCREMENT の書き方を差し替えます(構造は同じ)。

## テーブル一覧

| # | テーブル | 役割 | 移行件数 |
|---|---|---|---|
| 1 | conditions | 状態マスタ(新品/中古。将来: 不良/修理中/廃棄予定) | 2 |
| 2 | locations | 保管場所マスタ | 12 |
| 3 | categories | カテゴリマスタ(移行時は品目に紐付けない) | 12 |
| 4 | customers | 客先マスタ(移行時は登録しない。候補: 恵会/永和会/腎愛会/エミフル) | 0 |
| 5 | inventory_items | 品目マスタ | 109 |
| 6 | inventory_units | 個体(管理Noを持つ実物1台ごと) | 6 |
| 7 | inventory_counts | 棚卸(1回の棚卸=1行) | 2 |
| 8 | inventory_count_details | 棚卸明細(品目ごとの数量) | 160 |
| 9 | inventory_count_unit_results | 棚卸個体結果(個体ごとの有/無) | 8 |

Excel 111行 → 品目 109行(個体管理の「デスクトップ本体 中古」2行と「恵会眠りSCAN用無線ＡＰ予備 中古」2行が、それぞれ1品目+2個体になったため 2行減)。全行の対応は各CSVの `source_excel_rows` 列で追跡できます。

## 関係図

```
conditions ──┐
locations ───┼──< inventory_items >──< inventory_units
categories ──┤        │                      │
customers ───┘        │                      │
                      │                      │
inventory_counts >────┼── inventory_count_details (品目×棚卸: 数量)
                      └── inventory_count_unit_results (個体×棚卸: 有/無)
```

## DDL(MySQL 8.0 仮定)

```sql
-- 1. 状態マスタ
CREATE TABLE conditions (
  code        VARCHAR(20)  NOT NULL,                 -- 'new' / 'used' (将来 'defective','repairing','to_dispose')
  name        VARCHAR(50)  NOT NULL,                 -- 新品 / 中古
  sort_order  INT          NOT NULL DEFAULT 0,
  is_active   TINYINT(1)   NOT NULL DEFAULT 1,
  PRIMARY KEY (code)
);

-- 2. 保管場所マスタ
CREATE TABLE locations (
  id          INT          NOT NULL AUTO_INCREMENT,
  name        VARCHAR(100) NOT NULL,                 -- 原文のまま(例: ラック上から2段目右から４番目箱)
  sort_order  INT          NOT NULL DEFAULT 0,
  is_active   TINYINT(1)   NOT NULL DEFAULT 1,
  PRIMARY KEY (id),
  UNIQUE KEY uq_locations_name (name)
);

-- 3. カテゴリマスタ
CREATE TABLE categories (
  id          INT          NOT NULL AUTO_INCREMENT,
  name        VARCHAR(100) NOT NULL,
  sort_order  INT          NOT NULL DEFAULT 0,
  is_active   TINYINT(1)   NOT NULL DEFAULT 1,
  PRIMARY KEY (id),
  UNIQUE KEY uq_categories_name (name)
);

-- 4. 客先マスタ
CREATE TABLE customers (
  id          INT          NOT NULL AUTO_INCREMENT,
  name        VARCHAR(100) NOT NULL,
  is_active   TINYINT(1)   NOT NULL DEFAULT 1,
  PRIMARY KEY (id),
  UNIQUE KEY uq_customers_name (name)
);

-- 5. 品目マスタ
CREATE TABLE inventory_items (
  id                INT           NOT NULL AUTO_INCREMENT,           -- 内部ID(主キー)
  item_code         VARCHAR(20)   NOT NULL,                          -- 品目コード ITEM-000001(QR/バーコード用)
  item_name         VARCHAR(200)  NULL,                              -- 品名(原文)。移行データに空欄1件(Excel 73行目)があるため NULL 許可。新規登録画面では必須
  management_type   VARCHAR(20)   NOT NULL DEFAULT 'quantity',       -- 'quantity'(数量管理) / 'unit'(個体管理)
  category_id       INT           NULL,
  condition_code    VARCHAR(20)   NULL,                              -- 状態(空欄は NULL)
  stock_type        VARCHAR(20)   NOT NULL DEFAULT 'internal',       -- 在庫区分 'internal'(社内在庫) / 'customer_surplus'(客先備品余り)
  customer_id       INT           NULL,
  manufacturer      VARCHAR(100)  NULL,                              -- メーカー(任意。移行時は空)
  model_number      VARCHAR(100)  NULL,                              -- 型番(任意。移行時は空)
  serial_number     VARCHAR(100)  NULL,                              -- 数量管理品で1台だけの物用。個体管理品は inventory_units 側
  network_info      VARCHAR(255)  NULL,                              -- IPアドレス等(任意)
  location_id       INT           NULL,                              -- 保管場所(空欄は NULL)
  notes             TEXT          NULL,                              -- 備考(H列原文 + I列原文)
  is_active         TINYINT(1)    NOT NULL DEFAULT 1,                -- 有効/無効(物理削除しない)
  sort_order        INT           NOT NULL DEFAULT 0,                -- 表示順(Excel行順)
  created_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by        VARCHAR(50)   NULL,
  updated_by        VARCHAR(50)   NULL,
  source_excel_rows VARCHAR(50)   NULL,                              -- 移行元Excel行(例 '4;5')。移行後の検証用
  PRIMARY KEY (id),
  UNIQUE KEY uq_items_code (item_code),
  KEY idx_items_name (item_name),
  KEY idx_items_location (location_id),
  KEY idx_items_category (category_id),
  CONSTRAINT fk_items_category  FOREIGN KEY (category_id)    REFERENCES categories (id),
  CONSTRAINT fk_items_condition FOREIGN KEY (condition_code) REFERENCES conditions (code),
  CONSTRAINT fk_items_customer  FOREIGN KEY (customer_id)    REFERENCES customers (id),
  CONSTRAINT fk_items_location  FOREIGN KEY (location_id)    REFERENCES locations (id)
);

-- 6. 個体(個体管理品の実物1台ごと)
CREATE TABLE inventory_units (
  id                INT           NOT NULL AUTO_INCREMENT,
  item_id           INT           NOT NULL,
  management_no     VARCHAR(50)   NULL,                              -- 管理No(文字列。原文: 'NKC：0006','238','NKC-OZAKI' 等)
  serial_number     VARCHAR(100)  NULL,
  ip_address        VARCHAR(100)  NULL,
  status            VARCHAR(20)   NOT NULL DEFAULT 'in_stock',       -- 'in_stock'(在庫) / 'lent'(貸出) / 'in_use'(使用中) / 'disposed'(廃棄)
  location_id       INT           NULL,
  notes             TEXT          NULL,
  is_active         TINYINT(1)    NOT NULL DEFAULT 1,
  created_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by        VARCHAR(50)   NULL,
  updated_by        VARCHAR(50)   NULL,
  source_excel_row  INT           NULL,
  PRIMARY KEY (id),
  KEY idx_units_item (item_id),
  KEY idx_units_management_no (management_no),
  CONSTRAINT fk_units_item     FOREIGN KEY (item_id)     REFERENCES inventory_items (id),
  CONSTRAINT fk_units_location FOREIGN KEY (location_id) REFERENCES locations (id)
);

-- 7. 棚卸(1回の棚卸 = 1行)
CREATE TABLE inventory_counts (
  id            INT           NOT NULL AUTO_INCREMENT,
  count_name    VARCHAR(100)  NOT NULL,                              -- 棚卸名称(例: 2025/12/26 棚卸)
  base_date     DATE          NOT NULL,                              -- 棚卸基準日
  count_period  VARCHAR(100)  NULL,                                  -- 棚卸期間(文字列。移行データ: 棚卸2 に '2025/12/26')
  entry_date    DATE          NULL,                                  -- 入力日付(移行データ: 棚卸2 に 2026-01-08)
  start_date    DATE          NULL,                                  -- 棚卸開始日
  end_date      DATE          NULL,                                  -- 棚卸終了日
  status        VARCHAR(20)   NOT NULL DEFAULT 'preparing',          -- 'preparing'(準備中) / 'in_progress'(棚卸中) / 'confirmed'(確定済)
  notes         TEXT          NULL,
  created_by    VARCHAR(50)   NULL,
  created_at    DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  confirmed_by  VARCHAR(50)   NULL,
  confirmed_at  DATETIME      NULL,
  PRIMARY KEY (id)
);

-- 8. 棚卸明細(品目 × 棚卸)
CREATE TABLE inventory_count_details (
  id                    INT           NOT NULL AUTO_INCREMENT,
  count_id              INT           NOT NULL,
  item_id               INT           NOT NULL,
  count_quantity        INT           NULL,                          -- 棚卸数量(未確認時は NULL)
  confirm_status        VARCHAR(20)   NOT NULL DEFAULT 'unconfirmed',-- 'unconfirmed'(未確認) / 'confirmed'(確認済) / 'needs_check'(要確認)
  location_id_at_count  INT           NULL,                          -- 棚卸時保管場所
  counted_by            VARCHAR(50)   NULL,                          -- 棚卸担当者
  counted_at            DATETIME      NULL,                          -- 棚卸日時
  notes                 TEXT          NULL,                          -- 明細備考(その棚卸だけのメモ)
  created_at            DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at            DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by            VARCHAR(50)   NULL,
  updated_by            VARCHAR(50)   NULL,
  source_excel_rows     VARCHAR(50)   NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_details_count_item (count_id, item_id),
  CONSTRAINT fk_details_count    FOREIGN KEY (count_id)             REFERENCES inventory_counts (id),
  CONSTRAINT fk_details_item     FOREIGN KEY (item_id)              REFERENCES inventory_items (id),
  CONSTRAINT fk_details_location FOREIGN KEY (location_id_at_count) REFERENCES locations (id)
);

-- 9. 棚卸個体結果(個体 × 棚卸)
CREATE TABLE inventory_count_unit_results (
  id                INT           NOT NULL AUTO_INCREMENT,
  count_id          INT           NOT NULL,
  unit_id           INT           NOT NULL,
  result            VARCHAR(20)   NOT NULL DEFAULT 'unchecked',      -- 'unchecked'(未確認) / 'present'(有) / 'absent'(無)
  notes             TEXT          NULL,
  created_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  created_by        VARCHAR(50)   NULL,
  updated_by        VARCHAR(50)   NULL,
  source_excel_row  INT           NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uq_unit_results_count_unit (count_id, unit_id),
  CONSTRAINT fk_unit_results_count FOREIGN KEY (count_id) REFERENCES inventory_counts (id),
  CONSTRAINT fk_unit_results_unit  FOREIGN KEY (unit_id)  REFERENCES inventory_units (id)
);
```

## 補足

- **前回棚卸数・差異**(D-05): 保存せず、表示時に「同じ item_id で base_date がそれより前の、status='confirmed' の棚卸の明細」から取得して計算します。
- **個体管理品の棚卸**: 明細(数量)と個体結果(有/無)の両方を持ちます。画面では個体ごとに「有/無」をチェックし、数量は「有」の個数を自動集計する想定です。移行データでは Excel に数値があった個体を 'present' としています。
- **品名 NULL**: Excel 73行目(品名空欄、12/26=2)を「空欄のまま」移行するため item_name を NULL 許可にしています。新規登録・編集画面ではアプリ側で必須にします。
- **物理削除の禁止**(11. 有効/無効): 棚卸明細がある品目・個体は is_active=0 にするだけで DELETE しません。
- **文字コード**: 全角コロン・全角スペース・「⇔」「→」を含むため、utf8mb4 を使用します。
