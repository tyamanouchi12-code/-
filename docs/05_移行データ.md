# 移行データ(確定ルール適用済み)

生成スクリプト: `docs/migration/build_migration_data.py`(`python3 docs/migration/build_migration_data.py` で再生成)
出力: `docs/migration/*.csv`(UTF-8 BOM付き)

## 適用したルール

| 項目 | 適用内容 |
|---|---|
| 対象 | シート1 B〜H列 4〜114行目(111行)。A列は対象外。I列(99〜101行目)は備考に追記 |
| 原文保持 | 品名・状態・管理No・保管場所・備考の文字列は無変更。管理No 238/239 は文字列 |
| 空欄 | 品名(73行目)・状態(26行)・保管場所(39行)は NULL。棚卸数が空欄の行はその棚卸の明細を作らない |
| 結合セル | 保管場所の縦結合は各行に値を展開。G72:G73 は (a) 72行目のみ 13、73行目は空欄 |
| B案 | 管理Noのある6行(4,5,34,35,64,67)は個体。「品名+状態+保管場所」が同じ個体行は1品目にまとめ、個体を別レコードに(4+5 → 1品目2個体、34+35 → 1品目2個体) |
| 棚卸 | 1件目(F列): 基準日 2025-12-26、棚卸期間 NULL、入力日付 NULL。2件目(G列): 基準日 2026-01-06、棚卸期間「2025/12/26」、入力日付 2026-01-08 |
| 派生項目 | カテゴリ・メーカー・型番・客先・シリアル・ネットワーク情報は NULL(マスタのみ用意) |
| 重複候補 | 統合しない |

棚卸期間・入力日付の値は 2026-09-17 のご指示どおりです(棚卸1は両方空欄、棚卸2は棚卸期間=2025/12/26、入力日付=2026/1/8)。
